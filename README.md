# Контур Хаус

Сайт компании «Контур Хаус» — каркасные дома в скандинавском стиле.

Одностраничное приложение без сборки: весь код в `index.html`, рядом лежат фотографии проектов.

## Что внутри

- каталог из восьми проектов, каждый строится в любом из восьми размеров (6×4 … 12×10);
- калькулятор стоимости: контур, фундамент со сваями, фасад, кровля, утепление, окна, перегородки и двери, баня, доставка;
- калькулятор дома своего размера с выбором планировки-основы;
- редактор планировки: комнаты перетаскиваются мышью, окна и двери ставятся на стены;
- 3D-планировка, синхронная с редактором;
- страница «Технологии»: разрезы узлов, монтаж свай, сравнение материалов, конструктор пирога стены;
- корзина с полной спецификацией заказа, личный кабинет, светлая и тёмная темы.

## Запуск

Откройте `index.html` в браузере или отдайте папку любым статическим сервером:

```bash
python -m http.server 8000
```
